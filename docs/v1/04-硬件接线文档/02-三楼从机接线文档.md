## 四、传感器阈值配置

### 4.1 烟雾传感器 (MQ-2)

| 状态 | 电压范围 | 阈值 |
|------|----------|------|
| 正常 | < 500mV | - |
| 警告 | 500-1500mV | - |
| 火灾确认 | >= 1500mV | 60% |

### 4.2 雨滴传感器

| 状态 | 电压范围 | 阈值 |
|------|----------|------|
| 干燥 | > 2640mV | >80% |
| 小雨 | 1320-2640mV | 40-80% |
| 大雨 | < 1320mV | <40% |

### 4.3 传感器物理特性

```
烟雾传感器 (MQ-2):
- 清洁空气时：电阻小，电压低
- 有烟雾时：电阻大，电压高
- 阈值：>= 1500mV 触发火灾报警

雨滴传感器:
- 干燥时：电阻大，电压高 (>2640mV)
- 有水时：电阻小，电压低 (<1320mV)
- 阈值：< 1320mV 触发"大雨"→自动收衣服
```

## 五、通信协议

### 5.1 ESP-NOW 命令格式

```c
typedef struct {
    uint8_t command;     // 命令码
    uint8_t device_id;  // 设备ID
    uint8_t gpio_index;  // GPIO索引
    uint8_t value;       // 值
    uint8_t reserved[4]; // 保留
} iot_command_packet_t;
```

### 5.2 ASR UART 单字节命令

| 命令 | 含义 |
|------|------|
| 0x01 | 火灾报警 - 播报火灾警报 |
| 0x02 | 求助报警 - 播报紧急求助 |

## 六、软件调试

### 6.1 DEBUG_MODE

`DEBUG_MODE = 1` 时启用：
- 每 5 秒打印传感器 ADC 值
- GPIO47 按键可控制舵机角度循环

### 6.2 预期日志输出

```
I (1817) SENSOR_ADC: ADC initialized: Smoke=CH0(GPIO1), Rain=CH2(GPIO3)
I (1817) SENSOR_ADC: Thresholds: Smoke>=1500mV, Rain Heavy<1320mV, Rain Light<2640mV
I (1817) SENSOR_ADC: DEBUG MODE: 5s interval logging enabled
...
I (6868) SENSOR_ADC: [DEBUG] Smoke: 2800 mV, Rain: 2900 mV, Help: 1
I (6868) SENSOR_ADC: [DEBUG] Status -> Fire: 0, Rain: 0, Help: 0
```

### 6.3 传感器测试方法

1. **雨滴传感器测试**：
   - 干燥状态：雨滴区域干燥 → Rain > 2640mV → Dry
   - 加水测试：有水滴在传感器上 → Rain < 1320mV → Heavy Rain

2. **烟雾传感器测试**：
   - 正常状态：清洁空气 → Smoke < 500mV
   - 打火机测试：靠近打火机气体 → Smoke 上升
